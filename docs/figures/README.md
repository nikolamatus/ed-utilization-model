# Publication figures (v1.1)

These PNGs are **redrawn from frozen outputs**. They do not refit models
and do not overwrite locked files in `outputs/figures/`.

Regenerate with:

```bash
python docs/make_publication_figures.py
```

| 3 | `fig3_calibration_holdout.png` | Internal holdout calibration (not external validation) | `outputs/calibration.csv`, `outputs/holdout_calibration_v1_1.csv` |

regenerated by `python -m feasibility.run`.
